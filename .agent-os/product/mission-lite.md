# Juno Personal Finance - Mission Summary

> Condensed product mission for efficient AI context usage

## Product Overview

**Juno** is a mobile-first personal finance app implementing YNAB's envelope budgeting methodology for working adults (ages 25-40, $35k-$150k income) who need proactive financial control.

## Core Value Proposition

Transform reactive money management into proactive budget allocation through simplified envelope budgeting with real-time decision support.

## Target User Pain Points

- Overspending due to lack of spending visibility
- Financial stress from reactive money management  
- Difficulty saving consistently for goals
- Need for simple, mobile-optimized budgeting solution

## Key Features

1. **Overview Dashboard** - Financial health at a glance with envelope status
2. **Monthly Budget Allocation** - Drag-and-drop income allocation to envelopes
3. **Quick Transaction Entry** - One-tap expense logging with real-time balance updates
4. **Envelope Management** - Custom category creation and spending alerts

## Technical Stack

- **Frontend:** Next.js 15, TypeScript, Tailwind CSS v4, React 19
- **Backend:** Supabase (PostgreSQL + Auth + Realtime)
- **Deployment:** Vercel with PWA capabilities
- **Architecture:** Mobile-first responsive design with offline capability

## Competitive Advantage

- True envelope budgeting with mobile-optimized UX (vs YNAB's complexity)
- Real-time decision support (vs traditional tracking apps)
- Simplified workflow focusing on essential features
- Affordable pricing with freemium model

## Success Metrics

- **Engagement:** Daily expense entry, monthly budget completion
- **Financial Impact:** Reduced overspending, increased savings rate
- **Growth:** 70% month-1 retention, 4.5+ app store rating

## Development Philosophy

- User-centric design solving real pain points
- Mobile-first with quick interaction optimization
- MVP focus on core envelope budgeting workflow
- Type-safe development with comprehensive testing
